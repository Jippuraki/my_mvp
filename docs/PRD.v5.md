# PRD v0.5

## 1. 문제
패션 브랜드·온라인 등 안경원 밖에서 프레임을 산 사용자는, 자신의 프레임과 도수 조건을 실제로 처리해 줄 안경원을 알 수 없어서 여러 안경원에 직접 문의해야 한다.

## 2. 고객
홍대·연남·신촌에서 패션 브랜드나 온라인으로 프레임을 산 뒤, 도수 렌즈를 넣거나 특수 가공을 해야 하는데 맡길 단골 안경원이 없는 사용자.

## 3. 불편의 크기
- 현장 판매 경험: 주말 프레임 판매 약 15건 중 2~3건에서 도수 렌즈 삽입·가공 수요 발생.
- 홍대 현업 안경원 인터뷰: 외부 프레임 렌즈 가공 요청 월 약 20건.
- 고객 인터뷰: 집 근처 대형 체인에서 거절당하고 2곳을 더 돌다가 홍대 안경원까지 다시 방문한 사례.
