# PRD.v3 — After Frame

> 2026-10-15 기준 프로토타입(`index.html`)과 최근 결정을 반영한 문서예요. v2 대비 **[변경]**, **[추가]**, **[나중]**(정해졌지만 아직 안 만듦), **[보류]**(더 생각해 볼 것)로 표시했어요.

## 1. 문제
패션 브랜드·온라인 등 안경원 밖에서 프레임을 산 사용자는, 자신의 프레임과 도수 조건을 실제로 처리해 줄 안경원을 알 수 없어서 여러 안경원에 직접 문의해야 한다. (v2와 같음)

## 2. 고객
- **손님**: 신촌·홍대·합정·연남·이대에서 패션 브랜드나 온라인으로 프레임을 산 뒤, 도수 렌즈나 특수 가공을 맡길 곳이 없는 사용자. **[변경]** 시작 지역을 5곳으로 넓혔다.
- **안경원 [추가]**: 외부 프레임 가공 문의를 받는 안경원. 직접 매장 정보를 입력하는 쪽이다.
- 프레임 마니아(여러 개 모으고 렌즈를 자주 바꾸는 사람)와 외국인 사용자(한국어/English)도 쓰는 사람으로 본다.

## 3. 불편의 크기 (v2와 같음, 검증 중)
- 주말 프레임 판매 약 15건 중 2~3건에서 도수 렌즈 삽입·가공 수요 발생.
- 홍대 현업 안경원 인터뷰: 외부 프레임 렌즈 가공 요청 월 약 20건.
- 고객 인터뷰: 체인 안경원에서 거절당해 2곳을 더 돌고 홍대까지 다시 방문한 사례.
- 고객 검증 키트(판매자·안경원·마니아 인터뷰)로 숫자를 더 확인하는 중.

## 4. 핵심 가치 **[변경]**
1. 여러 안경원에 일일이 묻지 않고, 내 프레임을 가공할 수 있는 안경원을 확인한 뒤 바로 방문한다.
2. **[추가] 안경 카드**: 손님이 설명하기 어려운 안경 용어(무테/하금/소재 등)를 앱이 정리해 한 번에 보낸다. **안경원은 같은 것을 여러 번 묻지 않아도 된다.**
3. 위치, 영업 중 여부, 외부 프레임 정책, 택배 가능 여부를 한 번에 본다.
- **가격 [변경]**: 안경원이 가격을 입력하고 **공개할지 말지 직접 정한다.** 공개하면 그 매장 가격과 합계가 보이고, 비공개여도 손님은 **이 지역 렌즈 가격대**(시연용 시세)를 항상 볼 수 있다. 온라인 구매·결제·예약은 하지 않는다.

## 5. 핵심 흐름 다섯 단계 **[변경]**
1. 내 프레임을 알려 준다 (모양·소재, 모델 검색, 보관함, 사진으로 찾기).
2. 도수와 렌즈 기능을 고른다 (모두 선택 사항, "잘 몰라요" 가능). → 필요한 가공이 자동으로 정해진다.
3. 안경원을 찾을 지역을 정한다.
4. 조건에 맞는 안경원 중 한 곳을 고른다.
5. 문의를 보내거나 길찾기를 누른다.

## 6. 화면 **[변경: 3개 → 손님 5개 + 안경원 1개]**
| 번호 | 화면 | 보이는 것 |
|---|---|---|
| 01 | 조건 입력 | 내 프레임, 도수(선택), 지역, 알림 카드 |
| 02 | 렌즈 기능 | 틴팅·미러·편광·변색·블루라이트, 렌즈 사양(굴절률·설계) |
| 03 | 마이페이지 | 안경통(보관함), 교체·점검 알림, 내 장소, 이전 도수, 회원 정보, 보낸 문의 |
| 04 | 매장 목록 | 지도, 안경원 카드, 가공 가능 태그, 정렬(거리/가공 많은 순), 위치 바꾸기 |
| 05 | 매장 상세 | 가공 가능 항목, 외부 프레임 정책, 택배 가능 여부, 위치·영업 정보, 문의, 길찾기, "정보가 달라요" |
| 06 | **안경원 전용 [추가]** | 가입, 매장 정보 입력·수정, 받은 문의, 정보 확인일, 신고 목록 |

**결정(2026-10-15)**: 손님 화면은 5개로 확정, 안경원 전용 화면을 따로 둔다.

## 7. 기능 정리
**이미 있음**
- 사진으로 프레임 찾기 (시연용 → **정식 기능으로 키운다**, 8번 참고)
- 프레임 보관함·안경통, 교체·점검 알림, 이전 도수 기록, 굴절률 선택 가능 범위(시연용 기준)
- **문의 보내기**: 직접 쓴 글 + 안경 카드(프레임·테 종류 설명·소재·필요한 가공, 도수는 동의 시에만) + 연락받을 번호. 보낸 문의는 마이페이지에 모인다.
- **외부 프레임 정책**: 추가 비용 없음 / 가공비 별도 / 확인 중 / **받지 않음**. 받지 않는 매장은 목록에서 빠진다. 금액은 보여 주지 않는다.
- **영업 중 자동 계산**: 안경원이 입력한 영업시간으로 지금 시각 기준 계산.
- **가격 입력·공개 선택 [추가]**: 렌즈 가격(굴절률 4개), 렌즈 기능 추가 가격, 외부 프레임 가공비(구간 선택), 구멍 뚫기·홈파기 가공비. 공개 매장만 목록·상세에 가격이 나오고, 목록은 가격순 정렬을 지원한다(비공개는 맨 뒤).
- **택배 가능 표시**: 안경원이 입력한 값만 표시. 요청은 안경원에 문의로.
- **회원가입**: 손님은 **이름·전화번호만 필수**. 안경원은 매장 정보 입력(영업시간·휴무·외부 프레임 정책·택배·작업 기간·가공 항목·지도 서비스 등록 여부).
- **정확성 장치**: 정보 확인일 표시(한 달 넘으면 경고), 손님의 "정보가 달라요" 신고 → 안경원 화면.
- 영어 버전.

**[나중]** 길찾기를 매장 주소로 연결, 전화 문의 연결, 지도 서비스에서 영업시간 가져오기, 실제 서버·로그인.
**되돌림(2026-10-15)** 예상 비용과 가격순 정렬은 한때 뺐다가, 안경원이 공개 여부를 고르는 방식으로 다시 넣었다. 알선·유인 우려는 PR 합치기 전에 다시 판단한다.

## 8. 사진으로 프레임 찾기 — 정식 기능 **[변경]**
- 이유: 방향을 바꾸더라도 "사진으로 프레임 판별"은 핵심 기술로 쓸 수 있다.
- 결과는 **참고용**이다. 소재 확신도("확실해요/아마 그래요/몰라요")를 같이 보여 주고, 사용자가 고칠 수 있다.
- 개인정보 원칙: 사진은 판별 직후 지우는 것이 기본. 학습에 쓰려면 별도 동의를 받는다.
- 예상 비용(AI 호출, 사진 1장, 대략): 가장 작은 모델 약 0.4원 / 중간 모델 약 8원 / 큰 모델 약 17원. 하루 100장이면 월 약 1,300원 / 25,000원 / 50,000원. (이미지 약 1,500토큰 + 답 300토큰 가정, 환율 1,400원. 실제 값은 측정해서 확정)

## 10. 지켜야 할 원칙
- 안경원에서 소개 수수료를 받지 않는다. 목록·알림에 광고나 특정 매장 추천을 넣지 않는다.
- 문의는 손님이 고른 안경원 한 곳에만 전달한다. 답변은 안경원이 손님이 남긴 번호로 연락한다.
- 도수는 민감 정보라서 손님이 동의한 경우에만 카드에 넣는다.
- 예시·시연 데이터는 화면에 "시연용/가상/예시"로 표시한다.

## 12. 데이터 확보 계획 (안경원 정보를 채우는 법)
1. **후보 목록**: 공공데이터포털 "건강_안경업 조회서비스" 오픈API(무료, 활용신청 필요)로 이름·주소·영업상태(영업/폐업)를 받는다. 영업시간·전화·외부 프레임 정책은 없다.
2. **영업시간·전화**: 안경원이 직접 입력(가입 화면)이 기본. 지도 서비스에서 가져오는 경우 구글 Places가 영업시간을 공식 제공하지만 유료다. 카카오·네이버 공식 API에서 영업시간 제공은 확인하지 못했고, 지도 화면 수집(스크래핑)은 약관 위반 소지가 있어 하지 않는다.
3. **외부 프레임 정책**: 매장마다 다르다(무료/유료/불가, 체인은 이미지로 규정). 전화 확인과 공식 안내 확인으로 사람이 기록하고 "확인됨 + 날짜 + 출처"를 남긴다. 규정 이미지를 그대로 올리지 않고 요약해서 기록한다.
4. **순서**: 후보 수집 → 상위 매장 전화 확인 → 안경원 가입 초대(무료, 수수료 없음) → "확인됨" 배지.
5. **삭제·수정 요청 창구**를 두고 요청이 오면 바로 처리한다.

## 13. 지역 확장 기준 **[추가]**
- 기준: ① 영업 중인 안경원 수 ② 20~30대 유동·생활인구 ③ 패션 프레임 수요(편집숍·브랜드 매장 수). 지역별로 점수를 매겨 높은 곳부터.
- 후보(추정, 데이터로 확정 필요): **성수·건대입구 → 강남·신사 → 종로·을지로 → 잠실** 순.
- 확정 방법: 안경업 인허가 데이터(동별 영업 건수) + 서울시 생활인구(연령별) + 상권정보를 표로 합쳐 비교한다.
- 확장 조건 예: 현재 5개 동네에서 가입 안경원이 일정 수(예: 15곳)를 넘고 문의 응답이 이어질 때.

## 14. 보류 · 한계
- **[보류]** "가공 가능한 곳을 찾는다"는 핵심 가치는 방향 전환 가능성 때문에 더 생각해 본다. 비공개 매장은 가공비를 알 수 없어서 방문 전 문의가 필요하다.
- **[확인 필요]** 가격 표시는 CLAUDE.md의 "알선·법률 관련 기능은 먼저 물어봐요"에 걸릴 수 있다. 렌즈 가격대는 가상 시세이며, 실제 서비스에서는 근거 있는 시세 출처가 필요하다.
- 현재 매장 6곳과 가공 항목은 **가상 데이터**이고, 안경원 전용 화면에서 입력한 정보도 이 기기에만 저장된다 (서버 없음).
- 길찾기는 아직 매장 주소가 아니라 역 이름 검색으로 연결된다. 전화 문의도 연결되지 않는다 (둘 다 나중).
