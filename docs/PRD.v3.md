# PRD.v3 — After Frame

> 2026-10-15 기준 현재 프로토타입(`index.html`)에 맞춰 PRD.v2를 고친 문서예요.
> v2에서 바뀐 곳은 **[변경]**, 새로 생긴 곳은 **[추가]**, 아직 정하지 못한 곳은 **[결정 필요]** 로 표시했어요.

## 1. 문제
패션 브랜드·온라인 등 안경원 밖에서 프레임을 산 사용자는, 자신의 프레임과 도수 조건을 실제로 처리해 줄 안경원을 알 수 없어서 여러 안경원에 직접 문의해야 한다. (v2와 같음)

## 2. 고객
홍대·연남·신촌에서 패션 브랜드나 온라인으로 프레임을 산 뒤, 도수 렌즈를 넣거나 특수 가공을 해야 하는데 맡길 단골 안경원이 없는 사용자. (v2와 같음)
- **[추가]** 같은 프레임을 여러 개 모으고 렌즈를 자주 바꾸는 "프레임 마니아"도 쓰는 사람으로 본다 (보관함·알림 기능의 대상).
- **[추가]** 외국인 사용자를 위해 한국어/English 전환을 지원한다.

## 3. 불편의 크기 (v2와 같음, 검증 중)
- 현장 판매 경험: 주말 프레임 판매 약 15건 중 2~3건에서 도수 렌즈 삽입·가공 수요 발생.
- 홍대 현업 안경원 인터뷰: 외부 프레임 렌즈 가공 요청 월 약 20건.
- 고객 인터뷰: 집 근처 대형 체인에서 거절당하고 2곳을 더 돌다가 홍대 안경원까지 다시 방문한 사례.
- 진행 중: 고객 검증 키트(판매자·안경원·마니아 인터뷰)로 위 숫자를 더 확인하는 중.

## 4. 핵심 가치 **[변경]**
여러 안경원에 하나씩 전화하거나 방문하지 않고, 내가 가진 프레임을 실제로 가공할 수 있는 안경원을 확인한 뒤 바로 방문할 수 있다.
- **[추가]** 위치와 완성품 수령 방식(방문 수령 / 택배 가능)까지 한 번에 확인한다. 택배 가능 여부는 **안경원이 직접 입력한 값**만 표시하고, 택배를 요청하려면 안경원에 문의한다.
- 온라인 구매·결제는 하지 않는다. 결제와 상담은 매장 방문 때 한다.
- 가격은 보여 주지 않는다 (아래 8번 참고).

## 5. 핵심 흐름 다섯 단계 **[변경]**
v2는 "가공 유형 선택"이 1단계였어요. 지금은 사용자가 가공 이름을 고르는 대신 **프레임·도수·렌즈 기능을 입력하면 필요한 가공이 자동으로 정해져요** (예: 무테 → 구멍 뚫기, 천연 소재 → 열 쓰면 안 되는 가공).

1. 내 프레임을 알려 준다 (모양·소재, 모델 검색, 보관함에서 불러오기, 사진으로 찾기).
2. 도수와 렌즈 기능을 고른다 (모두 선택 사항, "잘 몰라요" 가능).
3. 안경원을 찾을 지역을 정한다 (현재 위치 / 본가 / 직장 / 직접 검색).
4. 조건에 맞는 안경원 중 한 곳을 고른다.
5. 길찾기를 누른다 (외부 지도 앱).

|---|---|---|---|

| 02 | 렌즈 기능 **[추가]** | 2 | 틴팅·미러·편광·변색·블루라이트 |
| 마이 | 마이페이지 **[추가]** | 1 보조 | 안경통(프레임 보관함), 교체·점검 알림, 내 장소, 이전 도수, 회원 정보 |
| 03 | 매장 목록 | 4 | 지도, 안경원 카드, 가공 가능 태그, 정렬(거리/가공 많은 순), 위치 바꾸기 |
| 04 | 매장 상세 | 5 | 가공 가능 항목, 외부 프레임 정책·작업 기간, 수령 방식(택배 가능 여부), 위치·영업 정보, 길찾기, 문의하기 |

## 7. 이번에 더해진 기능 **[추가]**
- **사진으로 프레임 찾기**: 사진으로 테 모양·소재를 추정해 채워 준다. 소재 확신도("확실해요/아마 그래요/몰라요")를 같이 표시. 지금은 **시연용**이고, 결정에 따라 **정식 기능으로 만든다** (AI 프레임 판별은 이후 방향 전환 때도 쓸 핵심 기술). 추정이 틀릴 수 있으므로 결과는 "참고용"으로 두고 사용자가 고칠 수 있게 한다.
- **프레임 보관함 / 안경통**: 프레임을 최대 8개까지 별명·사진·구매처·렌즈 맞춘 날과 함께 저장. 이 기기에만 저장.
- **교체·점검 알림**: 렌즈 12개월, 점검 6개월. 광고나 매장 추천은 넣지 않는다.
- **이전 도수 기록**: 최대 2개, 측정일·안경원(글자로만). 기본은 저장 안 함, 사용자가 켰을 때만 이 기기에 저장.
- **굴절률 선택 가능 범위**: 도수에 따라 고를 수 있는 굴절률 표시 (시연용 기준).
- **조건 카드**: 프레임·소재 확신도·필요한 가공·도수(동의 시에만)를 한 장으로 정리해 복사/문자로 사용자가 직접 전달. 앱은 문의를 대신 보내지 않는다.
- **데이터 신뢰 표시**: 매장 "확인됨" 배지, 정보 확인 날짜.
- **택배 수령 표시**: 안경원이 입력한 경우에만 "택배 가능"을 표시한다. 입력이 없으면 "매장 방문 수령"으로 보고, 택배는 문의하기로 안경원에 요청한다.
- **영어 버전**: 언어 전환 버튼, 번역표(`i18n.js`).

## 8. 안 할 것
v2의 목록을 유지하되, 현재 프로토타입과 맞는지 적었어요.

| 안 할 것 | 현재 상태 |
|---|---|
| 예약 | 안 함. 화면에 "결제·할인·예약을 받지 않아요" 안내 |
| 앱 내 결제 | 안 함 |
| 렌즈 온라인 판매 | 안 함 |
| 배송 | 앱은 배송하지 않음. 안경원이 입력한 "택배 가능" 여부만 표시하고, 요청은 안경원에 문의 (**결정 완료**) |
| 리뷰 커뮤니티 | 안 함. 나중에 한다면 별점·순위 없는 "가공 사례 기록"만 검토 |
| 가격 표시·가격 비교 | **빼기로 결정.** 예상 비용, 가격순 정렬, 가격 등록일 표시를 모두 제거한다 (가격이 매장 유인·알선으로 보일 수 있음). 앱 코드는 아직 그대로라서 제거 작업이 필요 |
| AI 프레임 자동 판별 | **하기로 변경.** 사진으로 프레임 찾기를 정식 기능으로 키운다 (**결정 완료**) |
| ERP 연동 | 안 함 (MVP2 후보로만 검토) |
| 시안 1/2/3 | 안 함. 알림 A/B 시안은 B안으로 확정하고 A/B 도구는 제거함 |

## 9. 지켜야 할 원칙 **[추가]**
- 안경원에서 소개 수수료를 받지 않는다. 알림·목록에 광고나 특정 매장 추천을 넣지 않는다.
- 앱은 정보 제공만 한다. 가공·결제는 매장과 직접 한다.
- 도수는 민감 정보라서 사용자가 동의한 경우에만 카드에 넣고, 저장은 이 기기에만 한다.
- 예시 데이터는 화면에 "시연용/가상"임을 표시한다.

## 10. 현재 한계와 다음 단계
- 매장 3곳, 브랜드 8개, 주소는 모두 **가상 데이터**. 길찾기는 매장 주소가 아니라 "홍대입구역/신촌역" 검색으로 연결됨.
- 지역은 홍대·연남·신촌만 지원. 그 밖은 "아직 준비 중" 안내.
- 다음: 실제 안경원 데이터 확보(동의 방식, 웹 공개 정보 위주 시작), 지도 API·실제 GPS, 길찾기를 매장 주소로 연결, 고객 검증 결과 반영, 로그인.
- 앱에서 먼저 고칠 것: 예상 비용·가격순 정렬·가격 등록일 제거, 택배 표시를 "안경원 입력 값"으로 바꾸기, 문의 "보냈어요" 문구 바로잡기.
- 안경원이 택배 가능 여부·가공 항목을 직접 입력하는 화면은 아직 없다 (현재는 고정 예시 데이터).
