안경원 매장 페이지 데모

왼쪽에서 사장님이 입력하면, 오른쪽 손님 화면이 바로 바뀌어요. 프레임 사진 한 장으로 상품이 등록되고, 가공 가능 항목과 렌즈 가격은 사장님이 직접 정해요.

시연용이에요. 가게 이름과 프레임, 가격은 모두 예시이고, 사진 분석은 가짜 분석이에요. 사진은 서버에 올라가지 않아요.

사장님 화면

1. 가게 정보

가격을 정확히 공개하기 꺼려지면 "○만~○만 원" 범위로 보여 줄 수 있어요.

2. 프레임 사진으로 상품 등록

시연용 가짜 분석이에요. 추정이니 맞는지 확인하고 고쳐 주세요.

3. 가공 가능 항목 (체크한 것만 손님에게 가능으로 보여요)

천연 소재(뿔·나무)는 열에 약해서 대부분 어려워요. 가능한 가게만 체크해 주세요.

4. 렌즈 가격표 (원)

기본 렌즈 가격은 굴절률별로, 기능은 추가 금액으로 입력해요. 모르는 칸은 비워 둬도 돼요.
